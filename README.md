# AI-Powered Predictive Escalation System for Public Grievance Redressal

## Overview
This project is designed to predict which public grievances are likely to escalate or remain unresolved. By using historical data and Machine Learning, the system automatically flags high-risk complaints, helping government departments take proactive action.

## Features
- **Citizen Portal (`index.html`)**: A simple interface for citizens to submit their complaints.
- **Admin Dashboard (`admin.html`)**: A priority queue for officials to view high-risk complaints and department-wise analytics.
- **AI/ML Model**: Predicts escalation risk and estimated resolution time.

## Tech Stack (Planned)
- **Frontend**: HTML, CSS, React.js
- **Backend**: Flask/FastAPI (Python)
- **Machine Learning**: XGBoost, NLP (IndicBERT)
- **Database**: PostgreSQL

## How to Use
1. Clone the repository: `git clone <your-repo-url>`
2. Open `index.html` to view the citizen portal.
3. Open `admin.html` to view the admin dashboard.
